# คำตอบสำหรับเดโมกรรมการ

ใช้กับแบบร่างที่มีข้อ 1 สองรายการ และข้อ 4 หนึ่งรายการ โดยส่งคำตอบทั้งสามในบัญชีผู้เรียนเดียว

1. **ข้อ 1 รายการแรก:** คัดลอกข้อความจาก `01_q1_clear.txt` ลงช่องคำตอบ เป็นตัวอย่างคำตอบชัดเจนจาก DS-003
2. **ข้อ 1 รายการที่สอง:** คัดลอกข้อความจาก `02_q1_review.txt` ลงช่องคำตอบ เป็นตัวอย่างคำตอบสั้นจาก DS-005 เพื่อเปิดให้ผู้สอนตรวจทานคะแนนและเหตุผล
3. **ข้อ 4:** อัปโหลด `03_q4_bst_answer.jpg` เป็นภาพคำตอบ BST จาก DS-104

หลัง AI ตรวจ ให้ผู้สอนดูคำตอบ เกณฑ์ คะแนน และ feedback ของทั้งสามข้อ จากนั้นแก้คะแนนหรือ feedback เฉพาะจุดที่มีเหตุผลให้แก้ อนุมัติผล แล้วเปิดบัญชีผู้เรียนเพื่อดูคะแนนที่ประกาศ

คะแนนอ้างอิงในชุดข้อมูลเดิม: DS-003 ผู้สอน 2 / AI 2, DS-005 ผู้สอน 0 / AI 1, DS-104 ผู้สอน 1 / AI 1 คะแนนจากการตรวจสดอาจต่างจากรอบเดิม ควรซ้อมหนึ่งรอบก่อนนำเสนอ
