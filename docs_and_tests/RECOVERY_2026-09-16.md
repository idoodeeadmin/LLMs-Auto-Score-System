## สิ่งที่พบ

สำเนา `e97e1ef` / `backup-session-before-revert` มีงานบางส่วน แต่ไม่ครบงานที่บันทึกใน IMPLEMENTATION_PROGRESS.md และ PRODUCT_UX_LOGIC_REVIEW.md การ build ใหม่อย่างเดียวจึงไม่พอ รายงานกู้ครั้งแรกที่บอกว่า UI กลับมาแล้วหมายถึงเฉพาะหน้าที่เห็น และไม่ใช่หลักฐานว่าฟีเจอร์ครบ

## วิธีการกู้

ค้นประวัติการแก้ไฟล์ของงานเดิมวันที่ 6–9 และ 15–16 กันยายน 2569 ใน Codex แล้วนำเนื้อหาไฟล์และ patch เดิมมาประกอบในโฟลเดอร์ recovery/reconstructed ก่อนเลือกคืนเข้าโปรเจกต์ ไม่รันคำสั่งบริการหรือแก้ฐานข้อมูลจากประวัติ ไม่ reset Git ทั้งโครงการ

patch เก่าบางส่วนใช้กับสำเนา commit ไม่ได้เพราะรูปแบบและฐานไฟล์ต่างกัน จึงเลือกเนื้อหาไฟล์ที่สร้างใหม่ครั้งล่าสุด รักษาฟังก์ชัน backend ที่ยังอยู่ และคืนส่วนที่ขาดใน frontend พร้อมตรวจ TypeScript และ tests ประวัติที่ประกอบไม่ได้ทั้งหมดไม่ถือว่ากู้สำเร็จโดยอัตโนมัติ

## งานตามรายงานเอกสารที่ยังมีอยู่ใน backend

OpenAI rubric/ตรวจคำตอบ, recovery ด้วย user_id, ขอบเขตสมาชิก–ห้อง–ข้อสอบ, ตรวจเวลา, จำกัดคำ/จำนวนภาพ, transcription, ซ่อนคะแนนก่อนอนุมัติ, ออกจากห้อง และแจ้งเตือน deadline ยังคงอยู่ในสำเนาปัจจุบัน ตรวจ regression suite แล้วผ่าน ไม่ได้นำ backend ที่ประกอบจาก patch ไม่ครบมาทับ
