# เกณฑ์ข้อ 2 ฉบับแยกส่วน (คะแนนเต็ม 2)

**โจทย์:** อธิบายว่าทำไม O(n log n) เหมาะกับข้อมูลใหญ่กว่า O(n²) และยกตัวอย่างอัลกอริทึม

## 1. คำอธิบายเหตุผล (0–1.5 คะแนน)

- **1.5:** อธิบายถูกว่าเมื่อขนาดข้อมูลเพิ่มขึ้น จำนวนงาน/เวลาแบบ O(n log n) โตช้ากว่า O(n²) จึงเหมาะกับข้อมูลขนาดใหญ่กว่า จะใช้คำพูด ตัวเลขเปรียบเทียบ หรือหลักการเดียวกันก็ได้
- **1.0:** สรุปทิศทางถูกและมีเหตุผลเกี่ยวกับการเติบโตของจำนวนงาน แต่เหตุผลยังไม่ครบหรือไม่เชื่อมกับข้อมูลขนาดใหญ่ชัดเจน
- **0.5:** บอกเพียงว่า O(n log n) เร็วกว่า/ดีกว่าเมื่อข้อมูลใหญ่ โดยไม่มีเหตุผลว่าทำไม แม้จะมีรายละเอียดอื่นที่ไม่เกี่ยวข้องหรือไม่ถูกต้อง แต่ต้องไม่กลับทิศทางข้อสรุปหลัก
- **0:** ไม่ตอบประเด็น กลับทิศทางความสัมพันธ์ หรืออธิบายหลักการผิดจนข้อสรุปหลักผิด

เลือกคะแนนส่วนนี้ได้เฉพาะ 0, 0.5, 1.0, 1.5 และไม่ให้คะแนนจากการมีคำสำคัญอย่างเดียวหากความหมายที่สื่อผิด

## 2. ตัวอย่างอัลกอริทึม (0–0.5 คะแนน)

- **0.5:** ยกชื่ออัลกอริทึมที่ใช้เป็นตัวอย่างของความซับซ้อนข้างต้นอย่างถูกต้องอย่างน้อยหนึ่งตัว เช่น Merge Sort, Heap Sort, Quick Sort (เฉลี่ย) สำหรับ O(n log n) หรือ Bubble Sort, Insertion Sort, Selection Sort สำหรับ O(n²) ยอมรับคำย่อที่รู้ได้ชัดว่าเป็นชื่ออัลกอริทึม เช่น “Merge” หรือ “Quick” ไม่บังคับให้เขียน Big-O กำกับชื่อ หากบริบทโจทย์ทำให้ทราบว่ากำลังยกเป็นตัวอย่าง
- **0:** ไม่ยกชื่ออัลกอริทึมที่เกี่ยวข้อง หรือระบุความซับซ้อนของตัวอย่างนั้นผิดอย่างชัดเจน

**คะแนนรวม = คะแนนคำอธิบาย + คะแนนตัวอย่าง** อยู่ในช่วง 0–2 ทีละ 0.5 คะแนน ตรวจสองส่วนแยกกัน ไม่ใช้ตัวอย่างมาชดเชยคำอธิบาย และไม่บังคับถ้อยคำตรงกับแนวคำตอบ
