# เกณฑ์ข้อ 2 ฉบับทดลอง (คะแนนเต็ม 2)

**โจทย์:** อธิบายว่าทำไม O(n log n) เหมาะกับข้อมูลใหญ่กว่า O(n²) และยกตัวอย่างอัลกอริทึม

## 1. คำอธิบายเหตุผล (0–1.5 คะแนน)

- **1.5:** อธิบายถูกว่าเมื่อขนาดข้อมูลเพิ่มขึ้น จำนวนงาน/เวลาแบบ O(n log n) โตช้ากว่า O(n²) จึงเหมาะกับข้อมูลขนาดใหญ่กว่า จะใช้คำพูด ตัวเลขเปรียบเทียบ หรือหลักการเดียวกันก็ได้
- **1.0:** สรุปทิศทางถูกและมีเหตุผลเกี่ยวกับการเติบโตของจำนวนงาน แต่เหตุผลยังไม่ครบหรือไม่เชื่อมกับข้อมูลขนาดใหญ่ชัดเจน
- **0.5:** บอกเพียงว่า O(n log n) เร็วกว่า/ดีกว่าเมื่อข้อมูลใหญ่ โดยไม่มีเหตุผลว่าทำไม
- **0:** ไม่ตอบประเด็น กลับทิศทางความสัมพันธ์ หรืออธิบายหลักการผิดจนสรุปผิด

เลือกคะแนนส่วนนี้ได้เฉพาะ 0, 0.5, 1.0, 1.5 และไม่ให้คะแนนจากการมีคำสำคัญอย่างเดียวหากความหมายที่สื่อผิด

## 2. ตัวอย่างอัลกอริทึม (0–0.5 คะแนน)

- **0.5:** ยกชื่ออัลกอริทึมที่เกี่ยวข้องอย่างน้อยหนึ่งตัวและสื่อได้ถูกว่าจัดอยู่ฝั่งใด เช่น Merge Sort หรือ Heap Sort เป็น O(n log n); Quick Sort เป็น O(n log n) โดยเฉลี่ย; Bubble Sort, Insertion Sort หรือ Selection Sort เป็น O(n²) ตามกรณีทั่วไป/แย่สุดที่เกี่ยวข้อง ยอมรับตัวอย่างอื่นที่จัดประเภทถูกต้อง
- **0:** ไม่ยกตัวอย่าง ยกชื่อที่ไม่เกี่ยวข้อง หรือจัดประเภทผิด โดยเฉพาะการกล่าวว่า Quick Sort มี O(n log n) ในทุกกรณี

**คะแนนรวม = คะแนนคำอธิบาย + คะแนนตัวอย่าง** อยู่ในช่วง 0–2 ทีละ 0.5 คะแนน ตรวจสองส่วนแยกกัน ไม่ใช้ตัวอย่างมาชดเชยคำอธิบาย และไม่บังคับถ้อยคำตรงกับแนวคำตอบ
